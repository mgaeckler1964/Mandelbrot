# Mandelbrot
 Apfelmänchengenerator


Requires Winlib and Gaklib.

Die wahrscheinlich 100 Millionste Variante.

Wer im Source Code nicht nachschauen will, auf welche Tasten das Programm
reagiert:

<pre>
Linke Maustaste:
Damit wird die Auswahl eines Bereichs iniziiert, in das hineingezoomt werden
soll. Beim Loslassen, wird der Zoom durchgeführt.

Rechte Maustaste:
Damit wird wieder heraus gezoomt.

Pfeiltasten:
Bewegt die Blickrichtung nach links, rechts, oben oder unten.
    Mit Control um die halbe Bildschirmseite,
    mit Shift wird nur der obere order rechte Rand bewegt,
    mit Alt der untere oder linke Rand.

Andere Tastenbefehle:
-  | Die Anzahl der Iterationen wird verkleinert,
   | mit Control halbiert,
   | mit Shift ist die Schrittweite kleiner.
+  | ... vergrößert.
   | mit Control verdoppelt,
   | mit Shift ist die Schrittweite kleiner.
b  | Wechselt die Farbe der Mandelbrotmenge.
B  | ... umgekehrte Reihenfolge
e  | Der Farbmodus wird geändert, linear, quadratisch oder logarithmisch.
g  | Der Graustufenmodus wird (de)aktiviert.
l  | Die Labels werden (de)aktiviert.
p  | Die Farbpalette wird gewechselt.
P  | ... umgekehrte Reihenfolge
^X |
q  | Beendet den Apfelmännchengenerator.
r  | Setzt den Zoomlevel auf den Anfangswert.
^N |
R  | Wie 'r' nur werden zusätzlich auch alle anderen Bildparameterzurückgesetzt.
^O | Öffnet eine Apfeldatei mit neuen Einstellungen
^S | Speichert eine Apfeldatei mit den aktuellen Einstellungen. Damit kannst Du
     jedes Bild wieder herstellen.
</pre>
